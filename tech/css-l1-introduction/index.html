L1.Introduction

发布于 2026年2月2日 | 分类: CSS
1 / 3下一篇 →L2.Selector

HTML是一个mark up document, document不选择如何展示他们, 我们通过CSS(Cascading Style Sheets)来控制如何展示他们.

具体来说, CSS大概可以控制: text, layout, animation等

HTML会变成一个DOM tree(Document Object Model)(某种接口), CSS会把它变成render tree

h1 {
  color: red;
  font-size: 2.5em;
}

p {
  color: aqua;
  padding: 5px;
  background: midnightblue;
}

上面的CSS语句包含了两个selecter, 每个selecter有数个declaration, 每个declaration是一个键值对.

在<a href="https://developer.mozilla.org/en-US/docs/Web/CSS/Reference">CSS Reference</a>找到这些繁琐的接口.

1.Add CSS

1.1.External stylesheets

创建一个style.css文件, 并在HTML文件的<head>中的任意地方添加如下:

<link rel="stylesheet" href="styles.css" />

1.2.Internal stylesheets

在HTML文件的<head>中添加<style>元素:

<style>
  p {
    color: purple;
  }
</style>

1.3.Inline styles

使用元素<span>的属性style可以将style的影响限制在这单个元素内:

<span style="color: purple; font-weight: bold">span element</span>

2.Common selectors

同时对两种元素使用相同的style:

p,
li {
  color: green;
}

通过class属性使用style:

<ul>
  <li>Item one</li>
  <li class="special">Item two</li>
  <li>Item <em>three</em></li>
</ul>
.special {
  color: orange;
  font-weight: bold;
}

不过要使用句点开头的selector .special{...}

通过descendant combinator选择某个元素内的某个元素:

li em {
  color: rebeccapurple;
}

上述选择了所有<li>内的<em>元素(DOM tree?)

通过next-sibling combinator选择某个元素的相邻某个元素:

h1 + p {
  font-size: 200%;
}

上述选择了所有<h1>的后一个<p>元素

css state可以选择一个元素的不同状态:

a:link {
  color: pink;
}

a:visited {
  color: green;
}

a:hover {
  text-decoration: none;
}

上述可以选择一个网址在被点击前和被点击后, 以及鼠标移动到网址上时的状态

上述操作可以组合:

h1 + p .special {
  color: yellow;
  background-color: black;
  padding: 5px;
}

这里选择了任意h1后的p里的special class元素

3.Others feature(粗略)

calc()可以做一点数学计算:

<div class="outer"><div class="box">The inner box is 90% - 30px.</div></div>
.outer {
  border: 5px solid black;
}

.box {
  padding: 10px;
  width: calc(90% - 30px);
  background-color: rebeccapurple;
  color: white;
}

calc(90% - 30px)其中90%是总长的百分之90.

transform属性可以跟一些函数:

.box {
  margin: 30px;
  width: 100px;
  height: 100px;
  background-color: rebeccapurple;
  transform: rotate(0.8turn);
}

@rules可以做一些特定的条件判断:

body {
  background-color: pink;
}

@media (width >= 30em) {
  body {
    background-color: blue;
  }
}
