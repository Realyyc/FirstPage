L4.Links

发布于 2025年12月22日 | 分类: HTML
← 上一篇L3.HTML document Structure4 / 8下一篇 →L5.Images

links是web的灵魂.

1.basic

​ link通常使用<a>元素和里面的href attribute (Hypertext Reference)实现:

<p>
  I'm creating a link to
  <a href="https://www.mozilla.org/en-US/">the Mozilla homepage</a>.
</p>

​ 标题和image的link, 直接将整个元素包括在内:

<a href="https://developer.mozilla.org/en-US/">
  <h1>MDN Web Docs</h1>
</a>
<p>
  Documenting web technologies, including CSS, HTML, and JavaScript, since 2005.
</p>

<a href="https://developer.mozilla.org/en-US/">
  <img src="mdn_logo.svg" alt="MDN Web Docs" />
</a>

​ 添加一个title, 可以在鼠标移动到anchor时出现title文字:

<p>
  I'm creating a link to
  <a
    href="https://www.mozilla.org/en-US/"
    title="The best place to find more information about Mozilla's mission and how to contribute">
    the Mozilla homepage</a
  >.
</p>

2.absolute and relative path

假设我们的目录结构长成这样:

creating-htperlinks
    contacts.html
    index.html
    pdfs
        project-brief.pdf
    projects
        index.html

根目录的名字叫做creating-htperlinks, 使用./与../ link to 当前根目录上的其他网页:

<p>
  Want to contact a specific staff member? Find details on our
  <a href="./contacts.html">contacts page</a>.
</p>
<p>Visit my <a href="./projects">project homepage</a>.</p>

他可以是一个html文件, 也可以是一个文件夹里的新的index.html

当然你可以直接link to外部网站

3.document fragment

Elements with id attribute 可以作为连接的对象:

<h2 id="mailing_address">Mailing address</h2>
<p>
  Want to write us a letter? Use our
  <a href="contacts.html#mailing_address">mailing address</a>.
</p>

只需要直接加一个#

4.How

一般来说, 服务器的文件系统在网页上是不可见的, 但对于我们简单的例子, 他是可见的, 我们可以直接通过URL访问资源: https://www.example.com/pdfs/project-brief.pdf

5.link to non-HTML resources

使用download属性提醒需要下载, download的值作为默认下载文件名称

<p>
  <a href="/large-report.pdf" download>
    Download the sales report (PDF, 10MB)
  </a>
</p>

<a
  href="https://download.mozilla.org/?product=firefox-latest-ssl&os=win64&lang=en-US"
  download="firefox-latest-64bit-installer.exe">
  Download Latest Firefox for Windows (64-bit) (English, US)
</a>

设置属性target="_blank"在打开link时自动使用新的网页, 而不是覆盖当前网页, 一般而言打开外部网站才会使用这种方法.

设置mailto:123@123.com形式的连接自动打开邮件:

<a href="mailto:nowhere@mozilla.org">Send email to nowhere</a>
