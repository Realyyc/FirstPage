L2.Selector

发布于 2026年2月6日 | 分类: CSS
← 上一篇L1.Introduction2 / 3下一篇 →L3.Box

上节粗略的介绍了一些selector, 现在详细介绍一下.

1.Type Selector

也叫type name selector或者element selector, 选择HTML的元素:

body {
  font-family: sans-serif;
}

span {
  background-color: yellow;
}

strong {
  color: rebeccapurple;
}

em {
  color: rebeccapurple;
}

2.Class Selector

使用.class_name会选择所有class属性值为class_name的任意HTML元素(不仅仅是span):

<h1 class="highlight">Class selectors</h1>
<p>
  Veggies es bonus vobis, proinde vos postulo essum magis
  <span class="highlight">kohlrabi welsh onion</span> daikon amaranth tatsoi
  tomatillo melon azuki bean garlic.
</p>

<p class="highlight">
  Gumbo beet greens corn soko <strong>endive</strong> gumbo gourd. Parsley
  shallot courgette tatsoi pea sprouts fava bean collard greens dandelion okra
  wakame tomato. Dandelion cucumber earthnut pea peanut soko zucchini.
</p>
body {
  font-family: sans-serif;
}

.highlight {
  background-color: yellow;
}

也可以指定特定元素的特定class: p.class_name{...}

body {
  font-family: sans-serif;
}

span.highlight {
  background-color: yellow;
}

h1.highlight {
  background-color: pink;
}

当一个元素有多个class时, 使用连续的点:

<div class="notebox">This is an informational note.</div>

<div class="notebox warning">This note shows a warning.</div>

<div class="notebox danger">This note shows danger!</div>
.notebox {
  border: 4px solid #666666;
  padding: 0.5em;
  margin: 0.5em;
}

.notebox.warning {
  border-color: orange;
  font-weight: bold;
}

.notebox.danger {
  border-color: red;
  font-weight: bold;
}

3.ID Selector

使用#选择id, 规则和class selector一样, 只不过一个HTML中的ID各不相同, 一个ID selector只会使用一次(没什么用的样子):

 body {
  font-family: sans-serif;
}

#one {
  background-color: yellow;
}

h1#heading {
  color: rebeccapurple;
}

4.Universal Selector

使用*选择所有元素:

* {
  margin: 0;
}

可以在使用descendant combinator时让代码更好读:

article *:first-child {
  font-weight: bold;
}

5.Presence and value selector

<h1>Attribute presence and value selectors</h1>
<ul>
  <li>Item 1</li>
  <li class="a">Item 2</li>
  <li class="a b">Item 3</li>
  <li class="ab">Item 4</li>
</ul>
li[class] { /* 选择所有li元素中有class属性的 */
  font-size: 120%;
}

li[class="a"] { /* 选择所有li元素中class属性为“a”的 */
  background-color: yellow;
}

li[class~="a"] { /* 选择所有li元素中class属性有“a”的, 比如“a b” */
  color: red;
}

li[class^="a"] { /* 选择所有li元素中class属性string开头为“a”的 */
  font-size: 120%;
}

li[class$="a"] { /* 选择所有li元素中class属性string结尾为“a”的 */
  background-color: yellow;
}

li[class*="a"] { /* 选择所有li元素中class属性string中有“a”的 */
  color: red;
}

6.Pseudo-class(class satae)

要选择元素<a>内所有的第一个<b>元素, 只需要 a b:first-child{...}:

<article>
  <p>
    Veggies es bonus vobis, proinde vos postulo essum magis kohlrabi welsh onion
    daikon amaranth tatsoi tomatillo melon azuki bean garlic.
  </p>

  <p>
    Gumbo beet greens corn soko endive gumbo gourd. Parsley shallot courgette
    tatsoi pea sprouts fava bean collard greens dandelion okra wakame tomato.
    Dandelion cucumber earthnut pea peanut soko zucchini.
  </p>
</article>
article p:first-child {
  font-size: 120%;
  font-weight: bold;
}

甚至可以: :first-child or *:first-child

7.Pseudo-element

选择一个元素内的某个位置, 比如选择元素<a>内<b>元素内的第一行a b::first-line{...}

<article>
  <p>
    Veggies es bonus vobis, proinde vos postulo essum magis kohlrabi welsh onion
    daikon amaranth tatsoi tomatillo melon azuki bean garlic.
  </p>

  <p>
    Gumbo beet greens corn soko endive gumbo gourd. Parsley shallot courgette
    tatsoi pea sprouts fava bean collard greens dandelion okra wakame tomato.
    Dandelion cucumber earthnut pea peanut soko zucchini.
  </p>
</article>
article p::first-line {
  font-size: 120%;
  font-weight: bold;
}

在一个元素内的开头或者结尾插入 b::before{...} or b::after{...}:

<p class="box">Content in the box in my HTML page.</p>
.box::before {
  content: "This should show before the other content. ";
  background-color: yellow;
}
