L2.HTML text

发布于 2025年12月17日 | 分类: HTML
← 上一篇L1.Basic HTML syntax2 / 8下一篇 →L3.HTML document Structure

1.标题

​ 使用六级标题可以让内容富有结构和语义:

<h1>Favorite body parts</h1>
<h2>brain</h2>
<p>The brain Lovely shape and color. Also does thinkin' stuff.</p>
<h2>feet</h2>
<p>The feet Knobbly and ugly, but useful for getting about.</p>

​ 而如下方式则没有特殊的标题语义, 虽然他可能长得很像标题

<span style="font-size: 32px; margin: 21px 0; display: block;">
  Is this a top level heading?
</span>

2.重点

​ 使用<em></em>和<strong></strong>突出显示段落中的句子, 前者通常是斜体, 后者通常是粗体.

<p>I am <em>glad</em> you weren't <em>late</em>.</p>
<p>This liquid is <strong>highly toxic</strong>.</p>

​ 注意, <b>, <i>, <u>可以做到粗体斜体下划线的效果, 但由于没有语义, 现在已经停止使用了.

3.list

​ html提供了三种list:

<ol>
    <li> </li>
    <li> </li>
    <li> </li>
</ol>

<ul>
    <li>...</li>
</ul>

<dl>
    <dt>...</dt>
    <dd>...</dd>
    <dt>...</dt>
    <dd>...</dd>
</dl>

​ 分别是ordered list, unordered list和 description lists, 前两者的元素是list item <li>, 后者的元素是description term <dt> 和 description definition <dd>

4.More Semantic(omitted)

​ 引用, 缩写, 地址(通讯, 物理), 时间, 代码, 上下标...这些在HTML中都有对应的element.

​ 注意, 引用有两种格式, 一种不外显:

  <q
    cite="https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/q">
    intended for short quotations that don't require paragraph breaks.
  </q>

​ 这段HTML会给句子自动加上双引号, 但不会显示网址

<p>
  According to the
  <a href="/en-US/docs/Web/HTML/Reference/Elements/blockquote">
    <cite>MDN blockquote page</cite></a>:
</p>

​ 使用了<a>(anchor)会产生点击可以进入网址的效果.
