L1.Basic HTML syntax

发布于 2025年12月16日 | 分类: HTML
1 / 8下一篇 →L2.HTML text

Ref https://developer.mozilla.org/zh-CN/docs/Learn_web_development/Getting_started/Your_first_website

1.element and tag

​ The element is the opening tag, followed by content, followed by the closing tag.

<p>My cat is vary grumpy</p>

​ nesting elements

<p>My cat is <strong>very</strong> grumpy.</p>

​ void elements 没有content和closing tag的元素

<img
  src="https://raw.githubusercontent.com/mdn/beginner-html-site/gh-pages/images/firefox-icon.png"
  alt="Firefox icon" />

2.Attribute

​ opening tag中的属性, 使用空格隔开, 属性值全部使用引号(quote, 单引号和双引号一样).

  <img src="https://raw.githubusercontent.com/mdn/beginner-html-site/gh-pages/images/firefox-icon.png" alt="Firefox" width="300">

​ bool属性不需要属性值, 只要出现就是true, 不出现就是false

<input type="text" disabled />

​ 网址可以省略引号, 不过我建议全部加上引号

<a href=https://www.mozilla.org/>favorite website</a>

​ 在引号内部, 使用&quot;表示引号

<a href="https://www.example.com" title="An &quot;interesting&quot; reference">A link to my example.</a>

3.Html Page

​ 我们来看一个完整HTML页面的代码:

<!doctype html>
<html lang="en-US">
  <head>
    <meta charset="utf-8" />
    <title>My test page</title>
  </head>
  <body>
    <p>This is my page</p>
  </body>
</html>

4.Meta Data

​ the head's job is to contain metadata about the document.

<head>
  <meta charset="utf-8" />
  <title>My test page</title>
</head>

​ 虽然有特别的element<meta>, 但不妨碍你认为整个head中的东西都是metadata

​ <title>不会在网页正文中出现, 但一般会在网页标题栏和网页收藏时出现, 这取决于你使用的浏览器的功能.

​ 很多的<meta>以<meta name="" content=""/>的格式出现

<meta name="author" content="Chris Mills" />
<meta
  name="description"
  content="The MDN Web Docs Learning Area aims to provide
complete beginners to the Web with all they need to know to get
started with developing websites and applications." />

​ author可以让访问者联系你, content是搜索引擎常用的

​ open graph data(og协议)也是一类metadata, 会在搜索引擎和需要缩略呈现你的网站时被呈现出来

<meta
  property="og:image"
  content="https://developer.mozilla.org/mdn-social-share.png" />
<meta
  property="og:description"
  content="The Mozilla Developer Network (MDN) provides
information about Open Web technologies including HTML, CSS, and APIs for both websites
and HTML Apps." />
<meta property="og:title" content="Mozilla Developer Network" />

​ favicon是网站自己的icon, 会在浏览器标签页边边出现. 直接在head中添加link就可以:

<link rel="icon" href="/favicon.ico" type="image/x-icon" />

​ 网站的icon很重要, 可以对不同的设备进行适配:

<!-- iPad Pro with high-resolution Retina display: -->
<link
  rel="apple-touch-icon"
  sizes="167x167"
  href="/apple-touch-icon-167x167.png" />
<!-- 3x resolution iPhone: -->
<link
  rel="apple-touch-icon"
  sizes="180x180"
  href="/apple-touch-icon-180x180.png" />
<!-- non-Retina iPad, iPad mini, etc.: -->
<link
  rel="apple-touch-icon"
  sizes="152x152"
  href="/apple-touch-icon-152x152.png" />
<!-- 2x resolution iPhone and other devices: -->
<link rel="apple-touch-icon" href="/apple-touch-icon-120x120.png" />
<!-- basic favicon -->
<link rel="icon" href="/favicon.ico" />

​ 添加CSS和JavaScript到你的head中:

<link rel="stylesheet" href="my-css-file.css" />
<script src="my-js-file.js" defer></script>

​ 前者是一个link, 后者是专门的script element, defer是bool属性, 旨在在html加载之后再加载js

​ 设置语言 虽然不在head里, 这样可以设置你网站的首要语言.

<html lang="en-US">
  …
</html>
