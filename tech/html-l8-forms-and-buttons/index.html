1.Buttons

<button>Press me</button>

buttons需要配合js或者form使用:

const btn = document.querySelector("button");
btn.addEventListener("click", () => {
  btn.textContent = "YOU CLICKED ME!! ❤️";
  setTimeout(() => {
    btn.textContent = "Press me";
  }, 1000);
});

2.Form basic

<form action="./submit_page" method="get">
    <h2>Subscribe to our newsletter</h2>
    <p>
        <label for="name1">Name (required):</label>
        <input type="text" name="name" id="name1" required />
    </p>
    <p>
        <label for="email">Email (required):</label>
        <input type="email" name="email" id="email" required />
    </p>
    <p>
        <button>Sign me up!</button>
    </p>
</form>

<form action="./submit_page" method="get"> <h2>Subscribe to our newsletter</h2> <p> <label for="name">Name (required):</label> <input type="text" name="name" id="name" required /> </p> <p> <label for="email">Email (required):</label> <input type="email" name="email" id="email" required /> </p> <p> <button>Sign me up!</button> </p> </form>

一个<form>元素内一般还有: <label>, <input>, <button>元素

<form>元素中的action和method属性决定了消息发送的地址和格式, 如果你输入了Name为Bob, Email为bob@bob.com, then当你按下按钮时网页会跳到:

/some/url/submit_page?name=Bob&email=bob%40bob.com

form内部可以添加各种基本的元素, 上面这个例子中就添加了<h2> and <p>, 后者是为了分行.

<input>元素中, 属性name是数据发送时以字典的形式, name的值就是key:

<input type="text" name="name" id="name" required />

<label>元素用于描述input, 他们之间通过id和for相关联

<label for="name">Name (required):</label>
<input type="text" name="name" id="name" required />

当然, 完全不使用label也行:

<label>
  Name (required):
  <input type="text" name="name" required />
</label>

但前者有更多的语义信息, 而且前者点击文字时会自动跳到输入栏.

<button>元素在form中默认承担提交信息的功能, 但其实还有各种button:

<button type="submit"></button>
<button type="reset"></button>
<button type="button"></button>

submit button只有在form中有其他button时才会声明, reset button最好不要使用, button button有什么用?

3.1.Radio button

连续的三个<input>, 他们的type和name的值都是一样的, 但需要指定不同的value, 也对应有不同<label>. 并且, checked代表默认选择, disabled代表当前不可用

<fieldset>
  <legend>Choose hotel room type:</legend>
  <div>
    <input
      type="radio"
      id="hotelChoice1"
      name="hotel"
      value="economy"
      checked />
    <label for="hotelChoice1">Economy (+$0)</label>

    <input type="radio" id="hotelChoice2" name="hotel" value="superior" />
    <label for="hotelChoice2">Superior (+$50)</label>

    <input
      type="radio"
      id="hotelChoice3"
      name="hotel"
      value="penthouse"
      disabled />
    <label for="hotelChoice3">Penthouse (+$150)</label>
  </div>
</fieldset>

<fieldset>元素用于将一组元素放在一起.

3.2.checkboxes

checkbox和radio很像, 除了checkbox的每个input有不同的name, 而没有value, 可以想象这是方便URL传输所有组合

4.Form validation

检查输入格式的正确性是一个很大的话题, 一般有两种validation:

  1. Client-side validation. 使用form validation attribute 或者 js, 这种方式可以给出立即的无效提示, 但无法防止恶意者发送有害信息.
  2. Server-side validation. 传统的方式会不信任客户端发来的所有信息, 会进行严格的检查, 但无法及时提示无效信息.
